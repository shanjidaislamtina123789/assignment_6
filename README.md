Project Name: DigiTools Platform

Description:
A modern e-commerce style platform designed according to Figma.  
Includes Navbar, Banner, Stats, Product Cards, Cart functionality, Pricing, and Footer — all fully responsive and beginner-friendly.  

Technologies Used:
1: React.js  
2: Tailwind CSS & DaisyUI  
3: JavaScript  
4: React-Toastify (NPM Package)  
5: JSON (for product data)  

Features:
1. Dynamic Cart System  
2. Product Cards with JSON Data  
3. Responsive & Interactive UI
